# 0001 · Build permit pre-review first

Date: 2026-11-06 · Status: accepted

## Decision

The first product is a permit pre-review tool. The plan catalog, material packages, and trade network come after the tool meets its phase 1 gate.

## Reasons

- The MCR gives a measurable answer key. Travis has access to a large set of MCRs and plan sets.
- Plans and cost estimates are a commodity. Capital-heavy prefab models failed.
- Austin zoning is covered by Archistar. Focus on non-zoning disciplines and surrounding jurisdictions.

## Result

Phase 0 collects and labels plan set + MCR pairs. The estimator takeoffs give a second answer key for quantity takeoffs.
